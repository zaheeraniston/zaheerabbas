# Zaheer Abbas — Creative Developer & Designer Portfolio

A showcase portfolio featuring interactive 3D physics, mouse parallax, an infinite dual-marquee gallery, interactive skills matrix, and a full-featured real-time **CMS Admin Panel** backed by **Supabase Cloud**.

---

## 🌟 Key Highlights

- **Hero 3D Parallax**: Interactive floating bust headshot, directional holographic arrow, and mouse-reactive floating 3D objects (Coffee, Key, Origami Plane, Diamond Ring).
- **Infinite Dual Marquee**: Continuous dual-direction photo tickers presenting visual works.
- **Engineering Matrix**: Interactive skills explorer with proficiency meters, technology tags, and category filtering (*Frontend*, *Backend*, *Mobile*, *DevOps & AI*).
- **Interactive Case Studies**: Detailed 3-photograph project grids with external links and live preview modals.
- **Embedded Studio CMS Admin Panel**: 
  - Direct UI access via `#admin` or keyboard shortcut **`Ctrl + Shift + A`**.
  - Master key protected session authentication.
  - Client-side image optimization (WebP/PNG automatic compression).
  - Add, edit, reorder, or delete **Services**, **Skills**, **Projects**, and **Marquee Gallery Photos**.
  - **Live Supabase Cloud Database synchronization** so changes update globally for every visitor in real-time.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/zaheeraniston/zaheerabbas.git

# Enter project directory
cd zaheerabbas

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

---

## 🔐 Admin Panel & Cloud Sync

1. Open your browser and navigate to `/#admin` or press **`Ctrl + Shift + A`**.
2. Log in using your master credentials.
3. Update any content, upload photos, or add new skills/services.
4. Click **"Save & Publish"** to broadcast changes live to the Supabase Cloud.

---

## 📦 Deployment

Deploy effortlessly to **Vercel**, **Netlify**, or **GitHub Pages**:
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
